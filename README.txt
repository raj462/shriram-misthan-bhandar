SHRIRAM MISHTAN BHANDAR - CLOUDFLARE/GITHUB WEBSITE

Files:
- index.html
- style.css
- script.js
- assets/

HOW TO USE:
1. Upload all files/folders to a GitHub repository.
2. Connect the repository to Cloudflare Pages.
3. Deploy from the main branch.
4. For /w/grihae, place a copy of this page in w/grihae/index.html for the first static version.
5. Replace the gallery placeholders with your real images in assets/ and update index.html image references.
6. Replace the Google Maps query if you want the second branch shown instead.

This is Version 1: a responsive static landing page. A dynamic database/admin/reseller builder can be added in the next phase.
